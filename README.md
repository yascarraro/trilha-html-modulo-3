# Módulo 3 - Trilha HTML

**Título:** Recriando Wikipedia, com um layout melhor :)

## Objetivo
Este desafio consiste em treinar com relação a estrutura do site, e também aplicar conhecimentos adiquiridos sobre semântica e acessibilidade.

## Desafio
Utilizar a estrutura básica já pré-montada de um layout simples com um pouco de CSS aplicado.

Criar da forma que desejar, e sobre os temas que quiser. O intuito aqui é divertir, e ao mesmo tempo aprender com o desafio.
